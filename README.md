# منظومة إدارة ومتابعة التكليفات — Public Demo

نموذج تجريبي عربي (RTL) لنظام مبسط لإدارة ومتابعة التكليفات.

> **تنبيه مهم:** هذا المستودع والنسخة المنشورة منه مخصصان للعرض والتطوير فقط. جميع أسماء المستخدمين والبيانات والتكليفات الموجودة في النسخة التجريبية بيانات افتراضية وغير مرتبطة بأي جهة أو شخص حقيقي.

## الفكرة

سير العمل اليومي المقصود بسيط:

`إنشاء التكليف → تأكيد الاستلام → تحديث العمل → إرسال للاعتماد → اعتماد وإنهاء / إعادة للتعديل`

الواجهة تركز على سرعة إنشاء التكليف، متابعة حالته، المحادثات والتحديثات، الإشعارات، سجل التنفيذ، والتقارير.

## التقنية

- React + TypeScript
- TanStack Router / Start
- Tailwind CSS + shadcn/ui
- Zustand للبيانات التجريبية المحلية
- واجهة عربية RTL ومتجاوبة

## تشغيل محلي

```bash
bun install
bun run dev
```

للتحقق من البناء:

```bash
bunx tsc --noEmit
bun run build
```

## الأمان والخصوصية

هذه النسخة **ليست نظاماً إنتاجياً ولا توفر مصادقة حقيقية**. تبديل المستخدمين والصلاحيات في الواجهة هدفه اختبار تجربة المستخدم فقط، ولا يجب الاعتماد عليه لحماية بيانات حقيقية.

لا تضع في هذا المستودع العام:

- كلمات مرور أو مفاتيح API أو Tokens.
- مفاتيح خاصة أو شهادات.
- عناوين IP داخلية أو تفاصيل بنية شبكية خاصة.
- أسماء أو معلومات موظفين حقيقية.
- تكليفات أو مرفقات أو وثائق تشغيلية حقيقية.
- ملفات `.env` أو قواعد بيانات أو نسخ احتياطية.

راجع [SECURITY.md](SECURITY.md) قبل إضافة أي تكامل أو بيانات جديدة.

## النشر

GitHub Pages، عند تفعيله، هو **نسخة عرض عامة فقط**. النشر الإنتاجي الحقيقي يجب أن يستخدم Backend ومصادقة وتخزيناً وقواعد بيانات وضوابط وصول مناسبة في بيئة خاصة.

## حالة المشروع

المشروع قيد التطوير والتبسيط. يتم الحفاظ على منطق الصلاحيات والتدقيق والتقارير، مع جعل تجربة الاستخدام اليومية أصغر وأوضح.
